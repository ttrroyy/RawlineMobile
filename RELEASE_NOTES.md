# RawlineMobile 1.1.5

# Вступайте в Telegram комьюнити, там общение и поддержка по нашим проектам: https://t.me/raw_comm

- Исправлены сбои тем и разметки главного экрана. Строка активного подключения сохраняется при объединении блоков. Выбор сервера при выключенном VPN оставляет его выключенным.
- В редакторе можно скрыть отдельный блок подписки. Меню открывается по нажатию на название, а «+» остаётся рядом с кнопкой обновления. В редакторе можно скрыть один из переключателей TUN и системного прокси.
- В Автовыборе обновлён алгоритм проверки и переключения профилей по логике Karing. Фильтр в окне статистики помещается на узком экране.
- При обновлении один раз включается «Защита tun0» для TCP. «Расширенная защита tun0» выключена по умолчанию. После обновления сохраняется выбор пользователя.
- В настройках TUN можно выбрать стек или оставить его выбор ядру. Добавлены резервные DNS, выбор наборов правил для DNS отдельных сайтов и автообновление геоданных.
- Исправлены импорт WDTT, передача ключа Soar и ручная капча FreeTurn. Обновлён qWDTT 1.4.5 и поддержка его ссылок и развёртывания. Уточнены сообщения при сбое запуска транспорта.
- Исправлены жесты подписок и управление группами с пульта Android TV. Подпись об обходе приложений скрывается при отключении маршрутизации подписки.
